# Apple Calendar 1.2.0

Initial GitHub distribution of the existing local Apple Calendar plugin.

- Fifteen local MCP tools for EventKit calendars, events, free time, native map locations, routes, and Calendar/Maps handoff.
- Advanced recurring schedules with explicit occurrence and series scopes.
- Portable Agent Plugins manifests and Codex compatibility manifests.
- A repository marketplace, standalone plugin ZIP, marketplace ZIP, and SHA-256 checksums.
- Swift sources and build scripts alongside the bundled Apple Silicon executable.

## Install

```bash
codex plugin marketplace add https://github.com/yueyang-yin/apple-calendar-plugin.git --ref main
codex plugin add apple-calendar@apple-calendar-local
```

Alternatively, download and extract `Apple-Calendar-Marketplace-1.2.0.zip`, then register the extracted `apple-calendar-marketplace` directory with `codex plugin marketplace add`. Install **Apple Calendar** from the **Apple Calendar Local** source in the desktop Plugins directory.

`Apple-Calendar-1.2.0.zip` contains only the standalone plugin for compatible ZIP importers. It is not the marketplace archive. Neither asset represents publication in OpenAI's public plugin directory.

## Platform and verification limits

Requires a local Mac running macOS 14 or later. The included executable is Apple Silicon only and ad hoc signed; Intel users must rebuild with Xcode Command Line Tools. Developer ID signing and notarization are not included.

The plugin runs on the Mac, including when accessed through a supported remote-host workflow. It does not run directly on iOS. Mobile remote access, Intel execution, every supported macOS version, Exchange writes, and cross-device synchronization have not been verified for this distribution.

Routine native and protocol checks do not commit calendar events. Live integration checks require a separate explicit write flag and are not needed to install the package.
